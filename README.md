# shell_emulator

Эмулятор командной оболочки ОС.

Вариант 13.

## Этап 1. REPL

На первом этапе реализован минимальный прототип консольного эмулятора командной оболочки.

Реализовано:
- консольное приглашение к вводу с именем VFS;
- разбор введённой строки на команду и аргументы;
- команды-заглушки `ls` и `cd`;
- команда `exit`;
- обработка неизвестных команд;
- игнорирование пустого ввода.

## Запуск

Для компиляции и запуска программы в Windows используется файл `run.bat`.

Запуск:

```bat
run.bat
```

## Пример использования

```text
my_vfs> ls test
Команда: ls
Аргументы: test

my_vfs> cd docs
Команда: cd
Аргументы: docs

my_vfs> unknown
Неизвестная команда: unknown

my_vfs> exit
Выход из эмулятора.
```
